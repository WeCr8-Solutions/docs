The desktop app is a Windows application that loads the full Jobline.ai platform in a dedicated window. It is functionally identical to the web app but designed for dedicated shop floor PCs and kiosk terminals.

## Why use the desktop app

- No browser tabs or distractions — full-screen dedicated window
- Session persists across reboots — operators don't have to log in again after a machine restart
- Single-instance lock — only one window opens per machine
- Suitable for wall-mounted tablets or dedicated terminals near machines

## Download options

Two versions are available from your account page:

| Version | File | Best for |
|---------|------|----------|
| Installer | `JobLineAI-Setup-1.0.0.exe` | Standard installation with Start Menu shortcut and uninstaller |
| Portable | `JobLineAI-Portable-1.0.0.exe` | Run without installing — good for USB drives or machines without install rights |

**System requirements:** Windows 10 or Windows 11, 64-bit.

## Install and launch

<Steps>
  <Step title="Download the installer">
    Download `JobLineAI-Setup-1.0.0.exe` from your Jobline.ai account page.
  </Step>
  <Step title="Run the installer">
    Double-click the file. Windows may show a SmartScreen warning — click **More info**, then **Run anyway**. This warning appears because the app is not yet code-signed; it is safe to proceed.
  </Step>
  <Step title="Complete the wizard">
    Follow the installation wizard. The app installs to `Program Files` and adds a Start Menu shortcut.
  </Step>
  <Step title="Launch and log in">
    Open **Jobline.ai** from the Start Menu. Log in with your existing Jobline.ai credentials.
  </Step>
</Steps>

<Note>
  The desktop app and web app share the same account and data. Logging in to either one gives you access to the same organization and jobs.
</Note>

## Self-hosted / ITAR deployments

If your shop handles ITAR-controlled or export-controlled technical data and requires data to remain on-premises, contact [support@jobline.ai](mailto:support@jobline.ai) for the self-hosted deployment guide. The self-hosted version can be configured to suppress all external telemetry.
