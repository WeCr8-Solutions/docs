Jobline.ai is actively expanding its integration ecosystem. The following capabilities are planned for upcoming releases.

## On the roadmap

<CardGroup cols={2}>
  <Card title="Additional ERP Systems" icon="building">
    SAP Business One, QuickBooks Manufacturing, Global Shop Solutions, and other job shop ERP platforms.
  </Card>
  <Card title="DNC / Program Transfer" icon="arrow-right-arrow-left">
    Push and pull CNC programs directly from Jobline.ai to your machines over FTP, SFTP, or serial connection.
  </Card>
  <Card title="Live Machine Telemetry" icon="gauge">
    Real-time spindle load, cycle time, and utilization data from CNC controls via the JobLine relay agent.
  </Card>
  <Card title="CAD/CAM File Attachments" icon="file-code">
    Attach G-code programs, setup sheets, and CAD files directly to work orders and operations.
  </Card>
  <Card title="Customer Portal" icon="user">
    Allow customers to view their order status in a read-only portal without a full Jobline.ai account.
  </Card>
  <Card title="MES Connectivity" icon="network-wired">
    Direct integration with shop floor MES platforms for bidirectional job status and production data.
  </Card>
</CardGroup>

## Request an integration

If there is an ERP, MES, or tool your shop relies on that you'd like to see integrated with Jobline.ai, let us know.

Email [support@jobline.ai](mailto:support@jobline.ai) with:
- The system name and version
- How you currently exchange data with it
- What data you need to flow into or out of Jobline.ai

<Note>
  Enterprise customers receive priority consideration for custom integration requests.
</Note>
